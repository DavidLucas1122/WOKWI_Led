**Nome:** David Lucas

---

## 📌 Descrição do Projeto

Este projeto tem como objetivo aplicar conceitos iniciais de **Internet das Coisas (IoT)** por meio da criação de um circuito simples de **LED piscante**.

A proposta consiste em programar o dispositivo para acender e apagar um LED em intervalos de tempo definidos, simulando um comportamento automatizado — conceito fundamental em sistemas embarcados e IoT.

---

## 🛠️ Componentes Utilizados

- 1x Microcontrolador (ex: Arduino)  
- 1x LED  
- 1x Resistor (220Ω ou 330Ω)  
- Jumpers  
- Protoboard  

---

## ⚙️ Funcionamento

O microcontrolador envia um sinal elétrico para o LED através de uma porta digital:

- **HIGH** → LED acende  
- **LOW** → LED apaga  

Entre cada mudança de estado, é aplicado um tempo de espera (delay), criando o efeito piscante.
